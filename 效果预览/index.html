P1 · 粒子星网

canvas 2D，粒子缓漂 + 邻近连线。最稳，适合铺全页背景，但不承担理念表达。

+2KB

P2 · 粒子聚形 · 闭环

粒子由随机态汇聚成闭环 Logo（开口圆环 + 核心方块 + 前箭头），驻留后散开循环。

推荐 · ~3KB

P3 · 3D 粒子点云舱

canvas 2D 手写透视投影，点云绕 Y 轴旋转成环形舱，带深度明暗与鼠标视差。

推荐 · ~3KB

P2 + P3 · 3D 聚形闭环（首屏主视觉）

粒子先以 3D 点云态缓慢翻滚，随后汇聚成闭环 Logo 并转为正面可读、微微呼吸；驻留后散开回到 3D 点云，循环播放。即方案推荐的 Hero 做法——既有 3D 空间感，又让粒子最终落到品牌母题上。

推荐组合 · ~4KB

P4 · CSS 3D 舱体

纯 CSS preserve-3d 旋转立方体，六面正好承载六阶段。结构感强，成本最低。

P5 · Three.js 真 3D 模型

真实光照与材质的 3D 模型（环形结 + 核心立方体）。沉浸感最强，但需要联网加载 CDN；若要离线自包含须额外打包 150–600KB，使现有整包体积翻倍以上。
