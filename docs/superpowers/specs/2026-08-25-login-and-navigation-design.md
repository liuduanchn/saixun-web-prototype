# 赛训智舱登录与多页面导航设计

## 目标

在不改变“行动优先驾驶舱”视觉方向和现有驾驶舱核心交互的前提下，增加演示登录入口，并让左侧九个菜单都能进入对应的独立工作页面。

## 已确认范围

- 演示账号为 `teacher`，密码为 `123456`。
- 认证只服务于本地参赛原型，不连接真实用户数据库或网络接口。
- 登录成功进入“竞赛项目驾驶舱”；未登录时只显示登录页。
- 会话保存在浏览器 `localStorage`，刷新后保持登录；退出后清除会话并返回登录页。
- 九个菜单均切换主工作区，驾驶舱现有任务、诊断抽屉和提示功能继续保留。
- 赛项解析、训练任务、作品诊断、模拟答辩和赛后复盘依据现有六张界面参考图实现；资源知识库、学习记录和设置中心沿用同一设计系统完成基础可交互页面。

## 信息架构

应用分为两层：登录门禁和已登录工作区。已登录工作区继续使用固定侧栏、顶部栏和主内容区；页面切换由当前菜单状态驱动，不新增后端路由依赖。页面刷新后默认回到驾驶舱，但登录状态保留。

## 页面职责

- 登录页：展示品牌、测试账号提示、账号密码输入、错误反馈和登录按钮。
- 竞赛项目驾驶舱：保留当前首页全部交互。
- 赛项解析中心：展示赛项材料、评分要素与能力映射、确认状态。
- 训练任务中心：展示阶段任务看板和评分覆盖情况。
- 作品诊断中心：展示评分原文、作品证据、诊断结果和修改任务入口。
- 模拟答辩室：展示问答记录、回答评价、证据缺口和教师补充评价。
- 赛后复盘：展示训练数据、能力成长、复盘结论与案例沉淀。
- 资源知识库：展示可筛选的模板、案例、评分材料等资源。
- 学习记录：展示个人学习轨迹、任务完成和能力变化。
- 设置中心：展示账号、通知和演示偏好设置。

## 视觉与交互

继续使用深海军蓝背景、电蓝主操作色、绿色完成态、橙色风险态和现有中文字体。登录页使用左右分区但保持同一品牌语言；业务页以密集但清晰的操作面板为主，不增加营销式首屏。菜单切换使用轻微淡入过渡，按钮和表单保持明确的悬停与焦点状态。

## 验收标准

1. `teacher / 123456` 可以登录，错误凭据不能登录并显示提示。
2. 刷新页面保持已登录状态；点击“退出登录”后回到登录页。
3. 九个菜单均显示标题匹配的独立内容，不再只改变选中状态。
4. 驾驶舱原有“生成修改任务”、任务勾选、诊断抽屉和账户菜单功能正常。
5. 生产构建、部署产物测试和新增行为测试全部通过。
